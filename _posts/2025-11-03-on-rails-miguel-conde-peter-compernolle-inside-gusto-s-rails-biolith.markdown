<p>In this episode of On Rails, Robby is joined by <a href='https://www.linkedin.com/in/miguelconde/'>Miguel Conde</a> and <a href='https://www.linkedin.com/in/petercompernolle/'>Peter Compernolle</a> from <a href='https://gusto.com/'>Gusto</a>, where they work on a &quot;biolith&quot;—two distinct Rails monoliths serving 600+ engineers. Peter leads the HIPAA-compliant benefits domain, while Miguel is extracting the time product from the main monolith. They explore how Gusto identifies boundaries, manages temporal data, handles eventual consistency, and navigates the trade-offs of GraphQL federation.</p><p><br/>🧰 <b>Tools &amp; Libraries Mentioned</b></p><p><a href='https://activeadmin.info/'><b>ActiveAdmin</b></a><b>:</b> Admin UI for Rails.</p><p><a href='https://github.com/Envek/after_commit_everywhere'><b>after_commit_everywhere</b></a><b>: </b>Run code after commits.</p><p><a href='https://www.datadoghq.com/'><b>Datadog</b></a><b>:</b> App and CI/CD observability.</p><p><a href='https://github.com/thoughtbot/factory_bot'><b>FactoryBot</b></a><b>:</b> Build test data.</p><p><a href='https://graphql.org/'><b>GraphQL</b></a><b>:</b> API layer for SPAs.</p><p><a href='https://kafka.apache.org/'><b>Kafka</b></a><b>:</b> Event streaming backbone.</p><p><a href='https://github.com/Shopify/packwerk'><b>Packwerk</b></a><b>:</b> Enforce boundaries in monoliths.</p><p><a href='https://github.com/paper-trail-gem/paper_trail'><b>PaperTrail</b></a><b>:</b> Model change auditing.</p><p><a href='https://react.dev/'><b>React</b></a><b>: </b>Front-end framework.</p><p><a href='https://sidekiq.org/'><b>Sidekiq</b></a><b>:</b> Background job processing.</p><p><a href='https://sorbet.org/'><b>Sorbet</b></a><b>:</b> Gradual Ruby types.</p><p><a href='https://www.typescriptlang.org/'><b>TypeScript</b></a><b>: </b>Typed JavaScript.</p><p><a href='https://github.com/Gusto/explicit_activerecord'><b>explicit_activerecord</b></a><b>:</b> Guard writes to models.</p><p><a href='https://www.rubykoans.com/'><b>Ruby Koans</b></a><b>: </b>Learn Ruby by practice.</p><p><a href='https://www.amazon.com/Cracking-Coding-Interview-Programming-Questions/dp/0984782850'><b>Cracking the Coding Interview</b></a><b>: </b>Interview prep book.</p><p><a href='https://engineering.gusto.com/'><b>Gusto Engineering Blog</b></a><b>:</b> Posts from Gusto engineers.</p>
