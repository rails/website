<p>In this episode of <em>On Rails</em>, Robby is joined by<a href='https://www.linkedin.com/in/hilary-stohs-krause/'> Hilary Stohs-Krause</a>, a Senior Software Engineer at<a href='https://redcanary.com/'> Red Canary</a>. They explore how engineering teams approach everyday performance work, from small Active Record optimizations to larger architectural decisions. Hilary shares insights from Red Canary&apos;s journey switching from React to Rails&apos; native Hotwire stack, how her team tackled flaky test failures that were slowing down continuous deployments, and some strong opinions about custom linters.</p><p><br/></p><p>🧰 Tools, Libraries, and Books Mentioned</p><ul><li><a href='https://github.com/rubocop/rubocop'><b>RuboCop</b></a> – Enforces Ruby style and conventions, with support for custom cops.</li><li><a href='https://github.com/sds/haml-lint'><b>haml-lint</b></a> – Linter for HAML templates to enforce consistent view code.</li><li><a href='https://eslint.org/'><b>ESLint</b></a> – JavaScript linter used for maintaining consistent code quality, especially in React.</li><li><a href='https://github.com/hadolint/hadolint'><b>HadoLint</b></a> – Linter for Dockerfiles to catch common issues and enforce best practices.</li><li><a href='https://github.com/natritmeyer/site_prism'><b>SitePrism</b></a> – Page-object model DSL for Capybara to reduce flaky system tests.</li><li><a href='https://sidekiq.org/'><b>Sidekiq</b></a> – Background job processor used in production Rails environments.</li><li><a href='https://turbo.hotwired.dev/'><b>Turbo</b></a> – Part of the Hotwire stack for reactive updates without full-page reloads.</li><li><a href='https://stimulus.hotwired.dev/'><b>Stimulus</b></a> – Lightweight JavaScript framework for enhancing HTML with small interactions.</li><li><a href='https://hotwired.dev/'><b>Hotwire</b></a> – A set of tools (Turbo + Stimulus) for building modern web apps without heavy JavaScript.</li><li><a href='https://www.penguinrandomhouse.com/books/552885/thinking-in-bets-by-annie-duke/'><b>Thinking in Bets</b></a> – A book about better decision-making under uncertainty, by Annie Duke.</li></ul><p><br/></p>
