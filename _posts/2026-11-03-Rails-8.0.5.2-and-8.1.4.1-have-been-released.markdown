Hello, Rails community!

Rails Versions 8.0.5.2 and 8.1.4.1 have been released. These are **security updates** addressing 21 security issues falling into a few themes:

* Possible arbitrary file read, file write and remote code execution in Active Storage image and video processing
* Possible Strong Parameters bypass in `Parameters#each_key`
* Possible IP spoofing in `remote_ip` through the `Forwarded` header (8.1 only)
* Multiple possible XSS vulnerabilities in Action View helpers, and one in the Active Support MessagePack serializer (8.1 only)
* Possible DoS vulnerabilities in Active Support `safe_constantize`, Action Controller Live streaming, and Active Storage proxy mode and filename handling
* Unsigned `Content-Type` and unenforced file size in Active Storage direct uploads to Google Cloud Storage
* Session handling issues: a destroyed session restored by `CacheStore`, a session cookie leaked by Active Storage proxy mode, and a missing `SameSite` attribute on session cookies
* Possible cache poisoning through content negotiation
* Possible signature replay in Action Mailbox Mailgun ingress

We strongly recommend upgrading as soon as possible.

Older versions of Rails are unsupported, and users are recommended to upgrade to at least the 8.0 series. Security support for the 8.0 series ends on November 7, 2026. See our [maintenance policy](https://rubyonrails.org/maintenance) for details.
